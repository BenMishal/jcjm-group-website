# JCJM Group Website

Premium Coming Soon landing page for **[jcjmgroup.in](https://jcjmgroup.in)**.

## Stack
- Pure HTML5 + CSS3 + Vanilla JS — no build step required
- Deployed via **Cloudflare Pages** (free)
- DNS managed through **Cloudflare**
- Domain registered at **Hostinger** (unchanged)

## Project Structure

```
├── index.html              ← Main page
├── assets/
│   ├── css/style.css       ← All styles (glassmorphism, animations, responsive)
│   ├── js/main.js          ← Minimal JS (particles, scroll reveal)
│   └── images/
│       └── favicon.svg     ← SVG favicon
├── _redirects              ← Cloudflare Pages: www → apex redirect
├── .gitignore
└── README.md
```

## Local Preview

Open `index.html` directly in any modern browser — no server needed.

## Deployment

This project auto-deploys to Cloudflare Pages on every push to `main`.

See the full deployment guide for Cloudflare Pages + Hostinger DNS setup.
